Репозиторій для спільної роботи над груповою презентацією з комп'ютерних наук.

## Склад команди та розподіл блоків

| № | Учасник (Прізвище Ім'я) | Блок / Тема | Файл конспекту |
|---|-------------------------|-------------|----------------|
| 1 | Ігор Мельников | Серверний захист та фільтрація загроз (Defense-in-Depth) | `blocks/01_мельников.md` |
| 2 | Ярмолюк Ілля | Атакуюча перспектива: цифровий слід, OSINT та вектори витоків | `blocks/02_ярмолюк.md` |
| 3 | [Прізвище Ім'я] | Клієнтська сторона: браузерний фінгерпринтинг і трекери | `blocks/03_прізвище.md` |
| 4 | [Прізвище Ім'я] | Наскрізне шифрування (E2EE) та криптографічні протоколи | `blocks/04_прізвище.md` |
| 5 | [Прізвище Ім'я] | Практична демонстрація (PoC) / Регуляції приватності | `blocks/05_прізвище.md` |

---

## Структура репозиторію

* `README.md` — опис теми, учасників та розподілу обов'язків.
* `blocks/` — конспекти блоків кожного учасника (`NN_прізвище.md`).
* `slides.pdf` — фінальна зведена презентація групи (додається на кроці 3).

## Правила роботи
1. Кожен працює у власній гілці (`feature/блок-прізвище`).
2. Кожен термін пояснюється простими словами одразу при першій згадці.
3. Усі твердження підкріплюються дійсними джерелами.
